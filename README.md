# Modern Calculator

A sleek, responsive, and fully functional Calculator built with HTML, CSS, and Vanilla JavaScript. This project features a modern glassmorphism aesthetic and supports both mouse and keyboard inputs.

## Features

- **Basic Arithmetic Operations**: Addition, subtraction, multiplication, and division.
- **Modern Glassmorphism UI**: Beautiful gradients, a blurred background effect, and smooth hover/active animations.
- **Keyboard Support**: Fully supports keyboard inputs for numbers (`0-9`), operators (`+`, `-`, `*`, `/`), `Enter` or `=` (equals), `Backspace` (delete), and `Escape` (clear all).
- **Responsive Design**: Designed to work seamlessly across desktop, tablet, and mobile devices.
- **Edge-case Handling**: Gracefully handles operations like division by zero and prevents multiple decimals.
- **Safe Logic**: Uses pure Vanilla JavaScript without relying on `eval()` for calculations.

## Technologies Used

- **HTML5**: Semantic structure.
- **CSS3**: Custom properties, Flexbox, Grid, Google Fonts (Outfit), and modern transitions.
- **Vanilla JavaScript (ES6)**: Object-oriented approach (ES6 Classes) to encapsulate calculator logic and state.

## How to Run

1. Clone or download this repository to your local machine.
2. Open the project folder.
3. Double-click on `index.html` to open it in your default web browser.
4. Start calculating!
